HOW TO INSTALL ON YOUR PC
1. Copy these .bmp files somewhere easy to find.
2. Open your EO client file gfx\\gfx023.egf in Resource Hacker.
3. For each PE number: Action -> Replace Resource (or Add) with that .bmp
4. Save gfx023.egf back into your EO gfx folder.
5. Reopen EO Pub Studio — Crimson item previews should show.

NOTE: Shield Resource ID 26 is NOT gfx023 — that is paperdoll art in gfx019/gfx020.
Inventory icons use the Gfx/Icon column (e.g. Shield Gfx 635).
